# 09: 高危提示与冲突提示

**What to build:** 用户允许高危操作时会得到提醒；同一工具、同一模式出现相互矛盾的决策时也会得到提醒。提示出现在两处：规则列表上每条规则的图标，以及输出页每个 Agent 的提示汇总。提示只提醒，不阻止生成。

**Blocked by:** 05, 06

**Status:** done

- [ ] 命令工具、MCP Server、内置工具都可以标记高危；单条规则也可以单独标记高危
- [ ] 高危提示只针对 `allow` 规则，满足任一条件即提示：所指工具高危；规则本身高危；所指内置工具为写入类，且模式为空、`/`、`~/` 或 `{{home}}/`
- [ ] 冲突提示：同一工具、同一模式出现不同决策时提示；各决策照常输出
- [ ] 规则列表上显示高危和冲突的图标；输出页汇总当前 Agent 的提示，并能定位到相关规则
- [ ] 提示随生成结果一起返回，带类型和相关规则的引用，界面只负责展示
- [ ] 生成接缝的测试覆盖：各个高危条件、`ask` 和 `deny` 不触发高危、冲突、内置工具规则只在所属 Agent 中提示
