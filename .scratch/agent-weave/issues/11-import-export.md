# 11: 导入与导出

**What to build:** 用户可以在同步页把整个工作区导出为 JSON 文件，文件名带日期；也可以导入一个工作区文件，替换当前工作区。导入前先确认。文件无效时显示具体原因，当前工作区保持不变。旧版本的文件自动迁移；比站点更新的版本被拒绝，并提示刷新页面。

导入流程同时是 13 中 Gist 拉取的校验入口。

**Blocked by:** 03

**Status:** done

- [ ] 导出内容就是工作区 JSON，不含 Gist Token、Gist ID 和本机设置
- [ ] 导入会校验结构：缺少字段、类型错误、引用了不存在的内部 ID 等情况返回原因码，界面翻译为具体提示
- [ ] `schema_version` 较旧时迁移，较新时拒绝；当前只有版本 `1`，迁移框架要能容纳以后的版本
- [ ] 导入整体替换当前工作区，执行前确认
- [ ] 工作区操作的测试覆盖：合法导入、各类无效文件、版本较新被拒绝、导入失败时原工作区不变
