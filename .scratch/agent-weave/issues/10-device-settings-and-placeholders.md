# 10: 本机设置与路径占位符

**What to build:** 用户在同步页的本机设置中选择操作系统（Linux、macOS、Windows）并填写用户名。输出时，规则模式和 MCP Server 内容中的 `{{home}}`、`{{user}}` 被展开成本机的真实路径。本机设置只保存在当前设备，不进入工作区，也不同步，因此同一个工作区在不同系统上各自生成正确的路径。

**Blocked by:** 03, 05, 06

**Status:** done

- [ ] 本机设置使用独立的本地存储键，不进入工作区，也不进入导出文件
- [ ] `{{home}}` 按操作系统展开为 `/home/<用户名>`、`/Users/<用户名>`、`C:\Users\<用户名>`；`{{user}}` 展开为用户名
- [ ] 展开作用于规则模式和 MCP Server 内容中的所有字符串值，权限输出和 MCP 输出都适用
- [ ] 本机设置不完整时，占位符原样保留，并产生“占位符未展开”的提示
- [ ] `${VAR}` 不受影响，原样输出
- [ ] 生成接缝的测试覆盖：各操作系统的展开、设置不完整、`${VAR}` 原样保留、占位符出现在 MCP 嵌套值中
