# 12: 合并预设与重置为预设

**What to build:** 站点更新预设后，老用户可以“合并预设”：只新增工作区里还没有的条目，从不覆盖用户改过的内容。用户也可以“重置为预设”，确认后用默认工作区整体替换当前数据。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 预设中各类条目的内部 ID 是固定值
- [ ] 合并预设按内部 ID 判断条目是否已存在，逐类（标签、命令工具、MCP Server、Agent 与其内置工具、规则）只新增不存在的条目，已有条目保持不变
- [ ] 预设条目的标识与工作区已有条目冲突时，跳过该条目，并在合并结果中列出
- [ ] 重置为预设前确认
- [ ] 工作区操作的测试覆盖：只新增、不覆盖已修改的条目、标识冲突时跳过并报告、重置
