# 08: 标签与筛选

**What to build:** 用户可以在“标签”页新增、重命名、删除标签，并给命令工具、MCP Server、内置工具打多个标签。工具列表可以按标签和名称筛选；规则列表可以按标签、决策、工具类型筛选，并保留 05 的归属筛选。删除标签后，原来引用它的工具显示该标签的标识，并带警告符号。

标签只用于分组和筛选，不影响任何输出。

**Blocked by:** 05, 06

**Status:** ready-for-agent

- [ ] 标签包括标识（唯一）和名称；可以新增、重命名、删除
- [ ] 三类工具都可以打多个标签
- [ ] 删除标签时不修改引用它的工具；残留的引用显示为标识加警告符号
- [ ] 工具列表可以按标签、名称筛选；规则列表可以按标签、决策、工具类型、归属筛选，多个筛选条件同时生效
- [ ] 预设先放入 spec 中列出的预设标签；命令工具的标签分配在 15 完成
- [ ] 测试证明增删标签不改变任何 Agent 的生成结果；工作区操作的测试覆盖删除标签后的悬空引用
