# 02: 命令工具到 Claude Code 权限输出（曳光弹）

**What to build:** 用户可以在“工具”页维护命令工具，在“权限规则”页为它们录入权限规则，然后在“输出”页看到 Claude Code 的权限配置，并能复制。这是第一条贯通全部层次的路径：工作区模型、生成接缝、界面。

工作区先只包含 `schema_version`、`updated_at`、命令工具、共享权限规则，以及一个只带权限输出的 Claude Code Agent 定义。预设先放少量命令工具和规则，够演示即可，完整预设在 15 完成。数据暂时只存在内存中，刷新即丢失，持久化在 03 完成。

**Blocked by:** 01

**Status:** done

- [ ] 工作区结构使用 snake_case 属性名，条目之间用内部 ID 引用，内部 ID 不在界面上显示
- [ ] 可以新增、编辑、删除命令工具（标识、可选描述）；标识重复时提示，不能保存
- [ ] 删除被规则引用的命令工具时，确认框显示受影响的规则数量，确认后连同规则一起删除
- [ ] 新增规则的流程是选工具、填可选模式、选决策（`allow`、`ask`、`deny`），并支持在同一工具下连续添加
- [ ] 规则列表按工具标识、模式自动排序，不支持拖拽
- [ ] 生成接缝：一个纯函数，输入工作区、Agent 内部 ID 和本机设置，返回结构化的输出结果；按模式是否为空选用命令工具的有模式或无模式模板（如 `Bash({command} *)`、`Bash({command} {pattern} *)`），模式中的 `*` 原样代入
- [ ] 同一决策内按最终字符串去重；输出顺序与规则列表一致
- [ ] 预览按属性路径显示完整嵌套的 JSON；“复制”只复制属性路径最末一段的键值对，不带外层花括号；每个决策有“复制内部”，只复制数组元素，不带方括号
- [ ] 输出旁显示 Claude Code 的作用域路径提示
- [ ] 生成接缝的测试覆盖：模板选择、去重、排序、复制文本、复制内部文本、空决策
