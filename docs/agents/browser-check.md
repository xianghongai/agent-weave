# 浏览器自查

涉及界面的改动，合并前自查一次；合并完成后，在集成分支上把受影响的页面整体再看一次。

## 起停开发服务器

用空闲端口，避开 5173（留给用户和用户的浏览器）。记下 PID，结束时按 PID 停：

```sh
mise exec -- pnpm dev --port 5191 > /tmp/dev-5191.log 2>&1 &
echo $! > /tmp/dev-5191.pid
```

```sh
kill "$(cat /tmp/dev-5191.pid)"
```

`pkill -f "vite.*<端口>"` 会匹配到执行它的 shell 自身，把当前命令也一起杀掉，不要用。

## 打开页面

用 `chrome-devtools-isolated` MCP（无头、临时配置）。多个子代理同时自查时会共用一个浏览器：只操作自己打开的页面，结束时关掉。

## 读取页面

- 需要整页结构，或要拿 uid 做交互时，用 `take_snapshot`。
- 只取文本、属性、数量时用 `evaluate_script`，比整棵无障碍树省得多。
- 需要看视觉效果时截图：宽屏和窄屏、深色和浅色各看一次。

## 网络

在“网络”面板确认运行时的请求只发往 `api.github.com`，其余只有本地开发服务器。
